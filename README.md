# Aneko动漫社 · 社团官方网站

一个**纯静态、零依赖、零构建**的动漫社网站：前台展示 + 作品投稿 + 招新报名 + 浏览器内后台管理。
风格参考了 [miku.coffee](https://miku.coffee/)（ANEKO动漫社）的站点结构，视觉换成**初音未来风**：青绿 / 水蓝 + 黑灰科技感。

---

## 一、30 秒跑起来

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **最简单（推荐）** | **双击 `index.html`** | 直接可用：导航、筛选、报名、投稿、后台全部功能都正常 |
| 本地服务器 | 在本文件夹执行 `python 起服务.py`，然后打开 <http://127.0.0.1:8000> | 想用 `http://` 地址预览时用这个 |
| 上线 | 把 3 个文件传到 GitHub Pages | 让所有人访问 |

> **两个坑，先说清楚：**
> 1. **不要用 `python -m http.server`**。Python 自带的这个服务器在 Windows 上不给页面声明 UTF-8 编码，浏览器会按本机编码（GBK）解码，中文会变成乱码。要起本地服务器，请用附带的 `python 起服务.py`（已经声明了 UTF-8），或者干脆双击打开。
> 2. 双击打开（`file://`）时，个别浏览器会限制「本地视频播放」和「IndexedDB 数据库」。如果你要用**上传图片 / 上传本地视频**这两个功能，请用本地服务器或部署上线后再试——其余功能双击即可。

## 三、三种改内容的方式

### 方式 1：用后台管理（推荐，不用写代码）

1. 打开网站 → 拉到页面最底部 → 点右下角的**「管理入口」**
2. 输入密码：**`admin123`**（进去后可在「站点设置」里改）
3. 左侧可以管理：公告、活动、作品审核、首页轮播、安利墙、成员部门、报名、站点设置、数据导出

后台能做的事：
- 新建 / 编辑 / 删除公告、活动、作品、轮播、推荐、成员、部门
- **作品审核**：社员投稿后是「待审核」，你点「通过」才会出现在作品展示页
- **报名管理**：查看招新与活动报名，一键导出 CSV（可用 Excel 打开）
- **数据与导出**：导出全部内容为 JSON 备份，或从备份导入

> 注意：后台修改保存在**你自己这台电脑的浏览器**里。别人打开网站看到的是代码里的默认内容。想让所有人都看到同一份内容，请用方式 2。

### 方式 2：直接改 app.js 里的数据（改了所有人都能看到）

打开 `app.js`，找到第 130 行左右的：

```js
const DEMO = {
  site: { name: "Aneko动漫社", slogan: "欢迎来到二次元的世界", ... },
  carousel: [ ... ],   // 首页轮播
  events:   [ ... ],   // 活动日历
  posts:    [ ... ],   // 公告
  works:    [ ... ],   // 作品
  members:  [ ... ],   // 成员
  departments: [ ... ],// 部门
  recommends:  [ ... ],// 番剧 / 游戏安利
  benefits: [ ... ],   // 加入理由
  reasons:  [ ... ],   // 常见问题
};
```

- **改社团名 / 联系方式**：改 `site` 里的 `name`、`email`、`qq`、`place` 等，全站页头页脚会自动跟着变。
- **加一场活动**：往 `events` 数组里复制一条，改 `title`、`start`（格式 `"2026-07-18T09:30"`）、`place` 即可。活动状态（即将开始 / 进行中 / 已结束）由时间自动算出来。
- **加一条公告**：往 `posts` 里复制一条，`pinned: true` 就是置顶。
- 时间字段也可以写成 `isoShift(7) + "T19:00"`，表示「从今天算起 7 天后 19:00」，这样演示数据永远不过期。

改完保存，刷新页面即可看到。

### 方式 3：直接点页面上的图片框

网站里所有图片位置都是**可点击的占位框**（写着「点击上传图片 · 推荐尺寸」）：

1. 点一下 → 选本地图片 → 立刻替换
2. 鼠标悬停会出现「更换 / 移除」按钮
3. 图片保存在浏览器本地数据库（IndexedDB），刷新、关机都不会丢

想换成自己的图片又不想一张张点？把图片放进文件夹，然后在 `app.js` 的数据里把 `img` 字段写成相对路径即可，例如：

```js
{ id: "wk_1", title: "雨夜的电车", img: "images/wk1.jpg", ... }
```

## 四、视频怎么放

作品展示页支持三种视频来源，在「上传作品」页面任选一种：

| 方式 | 做法 | 说明 |
| --- | --- | --- |
| 上传本地视频 | 选 MP4 / WebM 文件（≤120MB） | 存进浏览器 IndexedDB，刷新后仍能播放；**只存在你自己浏览器里** |
| 嵌入 B 站 | 粘贴 `https://www.bilibili.com/video/BVxxxx` | 自动变成在线播放器，**推荐**（不占空间，别人也能看） |
| 嵌入 YouTube | 粘贴 `https://youtu.be/xxxx` 或完整链接 | 同上 |
| mp4 直链 | 粘贴以 `.mp4` 结尾的地址 | 直接用浏览器播放器播放 |

社团的使用建议：**视频发到社团 B 站账号，再把链接填进网站**。这样不占空间、所有人都能看，也不会因为清缓存丢失。

## 五、从零上线到 GitHub Pages（详细步骤）

### 第 1 步：注册 GitHub
打开 <https://github.com/signup> 注册一个账号（免费）。

### 第 2 步：新建仓库
1. 登录后点右上角 **+ → New repository**
2. **Repository name** 填 `aneko-site`（随便取，英文）
3. 选 **Public**（Pages 免费版只支持公开仓库）
4. 点 **Create repository**

### 第 3 步：上传文件
1. 在仓库页面点 **uploading an existing file**（或 Add file → Upload files）
2. 把 `index.html`、`styles.css`、`app.js`、`.nojekyll` 一起拖进去
   - `.nojekyll` 在 Windows 里可能看不到：在资源管理器「查看」里勾上**文件扩展名**和**隐藏的项目**
   - 如果实在传不上 `.nojekyll` 也没关系，本项目没有下划线开头的文件，不影响
3. 下面 Commit changes 里随便写一句，点 **Commit changes**

### 第 4 步：开启 Pages
1. 仓库页面点 **Settings**（设置）
2. 左侧找到 **Pages**
3. **Source** 选 `Deploy from a branch`
4. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
5. 等 1-2 分钟，刷新这个页面，上方会出现你的网址：
   `https://你的用户名.github.io/aneko-site/`

把这个网址发到社团群里，所有人都能打开了。手机扫码也能开，报名表单在手机上做过专门适配。

### 第 5 步（可选）：绑定自己的域名
有域名的话，在 Pages 页面 **Custom domain** 里填进去，然后到域名服务商加一条 CNAME 记录指向 `你的用户名.github.io`。

### 更新内容
改完文件后回到仓库，点 **Add file → Upload files** 重新上传同名文件覆盖，等 1 分钟即生效。

> 国内访问 GitHub Pages 偶尔较慢。如果主要面向校内，也可以把这三个文件传到学校服务器、对象存储（阿里云 OSS / 腾讯云 COS）或 Gitee Pages，都是同样三个文件，不需要任何构建。

## 六、常见问题

**Q：为什么别人的电脑上看不到我在后台改的内容？**
A：因为这是纯静态站，没有服务器。后台数据存在**浏览器的 localStorage** 里，只属于你这台设备。要让所有人看到，请改 `app.js` 里的 `DEMO` 数据后重新上传（方式 2）。

**Q：招新报名的数据在哪里？别人提交的我能看到吗？**
A：报名信息同样存在**提交者自己的浏览器**里。招新现场的正确用法是：固定用一台电脑 / 一台平板打开报名页，让同学排队填写，结束后到后台「报名管理」导出 CSV。
如果想要真正收集所有人的报名，最简单的是加一个腾讯问卷 / 金数据链接，把「加入我们」页面的按钮改指向它。

**Q：上传的视频别人能看吗？**
A：本地视频只存在上传者的浏览器里，别人看不到。想让所有人看，请用 B 站链接。

**Q：清空浏览器缓存后数据丢了怎么办？**
A：后台「数据与导出」里可以随时导出 JSON 备份。养成改完内容就导出一次的习惯。图片和视频存在 IndexedDB，清理浏览器数据也会一并删除，重要素材请同时存云盘。

**Q：我想换配色怎么办？**
A：打开 `styles.css`，最上面 `:root` 里几行就是主题色：
```css
--miku: #39e6d0;      /* 主色：青绿 */
--blue: #3aa0ff;      /* 水蓝 */
--pink: #ff6fb5;      /* 辅助：粉色 */
--violet: #8b6bff;    /* 辅助：紫色 */
```
改这几个值，全站按钮、渐变、光晕、图标颜色会一起变。

**Q：页脚那些社交图标点了没反应？**
A：它们目前是占位。在 `app.js` 的 `initShell()` 里，把 `items` 每一项的 `href` 填上你的 B 站主页 / 微博 / 公众号链接即可。

**Q：怎么确认站点没坏？**
A：打开 `selfcheck.html`，它会自动跑几十项测试（路由、筛选、点赞、报名、投稿、审核、导出、主题、移动端布局、数据持久化），左侧列出每一项通过还是失败。改完代码后建议跑一次。

## 八、技术说明

- **纯原生**：HTML + CSS + 原生 JavaScript（IIFE + 事件委托），没有框架、没有打包、没有 npm
- **零外部请求**：不使用 CDN、外部字体、图标库；图标全部是内联 SVG，断网也能完整显示
- **存储**：文本内容 → `localStorage`；图片 / 视频 → `IndexedDB`（`aneko_media` 库）
- **安全**：所有用户输入都经过 HTML 转义再插入页面；管理密码只用于防误操作，不具备真实安全性
- **可访问性**：主要交互元素带 `aria-label`，支持 `prefers-reduced-motion`（系统开启「减少动态效果」时自动关闭粒子动画）
